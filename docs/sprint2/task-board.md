# Таблиця розподілу задач — Спринт 2

> Продукт: «Персонал+» · Спринт 2 «Аудит вимог і стратегія» · Дата планування: 19.10 · Оновлено: 20.10 · Команда E (ФБ-45)
> Артефакт **Скрам-майстра** (Вилінська Злата). У команді з 3 осіб Скрам-майстер/рецензент поєднується з Керівником тестування.

**Ролі Спринта 2:** Злата — Керівник тестування + Скрам-майстер/рецензент; Аліна — Тест-аналітик; Юлія — Інженер з тестування.

## Розподіл розділів SRS (кожен розділ — ≥2 незалежні аудитори)
| Розділ SRS | Аудитори | Індивідуальний аркуш |
|---|---|---|
| 1–2. Вступ, терміни, обмеження (§2.3) | **Аліна + Злата** | «Аркуш — Аліна», «Аркуш — Злата» |
| 3. Функціональні (F-) | Злата + Аліна | «Аркуш — Злата», «Аркуш — Аліна» |
| 4. Інтерфейс (GUI-) | Аліна + Юлія | «Аркуш — Аліна», «Аркуш — Юлія» |
| 5. Бізнес-логіка (BL-) | Юлія + Злата | «Аркуш — Юлія», «Аркуш — Злата» |
| 6. Нефункціональні (P-/S-/U-/D-) | Злата + Юлія | «Аркуш — Злата», «Аркуш — Юлія» |

Кожен аудитор веде **власний аркуш** у `requirements-defects.xlsx` (листи «Аркуш — …»); Тест-аналітик зводить їх у лист «Реєстр». Так видно, що кожен розділ перевірили двоє незалежно.
