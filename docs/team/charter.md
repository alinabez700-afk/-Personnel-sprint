## Методологія, методи і прийоми
**Методологія — гнучка (полегшений Scrum):** двотижневі спринти, Sprint Planning, асинхронний standup, Demo + ретро, ротація ролей.

**Методи (Спринт 3):** проєктування тест-кейсів за структурою з шести полів; покриття вимог (позитивні/негативні, класи еквівалентності, граничні значення); виконання на demo з веденням журналу; оформлення звітів про дефекти; рецензування за чек-листами.

**Прийоми:** незалежні кейси (кожен починається з відкриття застосунку); «один дефект — один звіт»; простежуваність «вимога → кейс → виконання → дефект»; ретроспектива Start/Stop/Continue.
